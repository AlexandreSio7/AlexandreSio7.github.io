## 🛠️ Projets Techniques Présentés

Ce portfolio documente mes réalisations techniques en administration système, réseau et cybersécurité :

* **Serveur WDS / MDT :** Automatisation et standardisation du déploiement d'images Windows.
* **Stratégies de Groupe (GPO) :** Sécurisation et administration d'un environnement Active Directory.
* **Gestion de Parc (GLPI & Atera) :** Inventaire matériel/logiciel et supervision / prise en main à distance.
* **Serveur Gestsup :** Déploiement d'une solution LAMP/WAMP de ticketing pour le support N1.
* **Firewall Sophos :** Configuration de règles de filtrage et sécurisation réseau.

## 🎨 Architecture & Design

Pour me démarquer des templates classiques, j'ai opté pour une conception "From Scratch" (sans framework lourd comme Bootstrap) :
* **UI/UX :** Design orienté **Glassmorphism** (effets de verre dépoli, transparences, lueurs néon).
* **Structure :** Approche *Single Page Application* / *Dashboard* pour les fiches de projets, bloquant le scroll global pour une immersion totale.
* **Responsive :** Adaptation complète pour les supports mobiles (Flexbox & CSS Grid).
